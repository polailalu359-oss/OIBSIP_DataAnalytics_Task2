# Clipkart Sales Data Analysis - Power BI Project

## 📊 Overview
This is a minor project analyzing e-commerce sales data from Clipkart using Microsoft Power BI. The project focuses on transforming raw sales data into meaningful visual insights through interactive dashboards.

## 📁 Files
- `Clipkart_Sales_Data_Minor_Project.pbix` – Power BI dashboard file
- `clipkart_ecommerce_data.csv` – Raw e-commerce sales dataset

## 🎯 Objective
To analyze e-commerce sales data and identify key trends, patterns, and insights related to sales performance, customer behavior, and product categories.

## 🛠️ Tools Used
- Microsoft Power BI
- Excel/CSV for data source

## 📈 Key Features
- Interactive dashboards and visualizations
- Sales trend analysis
- Data cleaning and transformation using Power Query
- DAX measures for KPIs

## 🚀 How to Use
1. Download the `.pbix` file
2. Open it using Power BI Desktop
3. Explore the interactive visuals and filters
